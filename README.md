# MAFIA

텍스트 기반 마피아 추리 웹게임 1차 제작 폴더입니다.

## 실행 방법

1. VS Code에서 이 폴더를 엽니다.
2. `index.html`을 브라우저로 엽니다.
3. 또는 VS Code Live Server 확장으로 실행합니다.

## 폴더 구조

```text
mafia-detective-game/
├─ docs/
│  ├─ rules.md
│  ├─ npc.md
│  ├─ locations.md
│  ├─ clue-system.md
│  └─ development-log.md
├─ index.html
├─ style.css
└─ game.js
```

## 현재 상태

- 룰 문서 작성 완료
- 1인 테스트용 웹게임 뼈대 포함
- 2인 비공개 단서/채팅은 아직 미구현
- 단서 생성은 테스트용 단순 버전
